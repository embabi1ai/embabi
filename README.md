# مساعد العنبر – Poultry Assistant

تطبيق أندرويد متكامل لإدارة مزارع الدواجن وتتبع الدورات، العلف، النافق، السبلة، أجور العمال، والمهام اليومية.

## مميزات التطبيق
- **إدارة دورة التربية**: تتبع عدد الكتاكيت وعمر الدورة ودرجة الحرارة.
- **قسم النافق**: تسجيل النافق اليومي وحساب الفراخ المتبقية تلقائيًا.
- **قسم العلف**: تتبع استهلاك العلف اليومي والتراكمي.
- **قسم السبلة**: تسجيل عربات السبلة وأسماء العمال المسؤولين.
- **قسم العمال والأجور**: حساب يوميات العمال تلقائيًا (الحضور، نصف اليوم، الغياب).
- **قسم المهام**: تنظيم مهام العنبر وتحديد المسؤولين عنها.
- **قاعدة بيانات SQLite محلية**: حفظ جميع البيانات دون اتصال بالإنترنت.

## كيفية البناء باستخدام GitHub Actions
1. قم برفع محتويات هذا المستودع إلى مستودع جديد على GitHub.
2. اذهب إلى تبويب **Actions** في مشروعك على GitHub لتتبع عملية البناء تلقائيًا.
3. بعد اكتمال البناء بنجاح، قم بتنزيل ملف الـ APK من قسم **Artifacts**.
